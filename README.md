# Web-development-

Websites to test.

## HWY 99 Cannabis Co. — homepage

Single-page glassmorphism homepage for a fictional dispensary. No build step
required — open `index.html` directly, or serve the folder:

```
python3 -m http.server 8000
# then visit http://localhost:8000
```

Files:

- `index.html` — markup (age gate, nav, hero, strains, categories, story, visit, footer)
- `styles.css` — earthy palette + glassmorphism primitives
- `script.js` — age gate, mobile nav toggle, scroll reveal
- `assets/logo.svg` — recreated highway-shield logo
